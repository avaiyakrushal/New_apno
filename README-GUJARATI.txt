Apno — Android સોર્સ પ્રોજેક્ટ
============================
આ Bolo Hi ની ફાઇલ કે એસેટની નકલ નથી. પોતાનો A લોગો, એપ આઇકન અને ટીલ/ગોલ્ડ બેકગ્રાઉન્ડ છે.
હાલ સ્થાનિક પ્રિવ્યૂ: ટેક્સ્ટ અને ગેલેરી ફોટો પોસ્ટ લખવી/કાઢવી તથા Like કરવી, રૂમ બનાવવું/કાઢવું, રૂમ સ્ક્રીન ખોલવી, પ્રોફાઇલ નામ તથા સ્થાનિક ID સાચવવા.
Google/Facebook/મોબાઇલ લોગિન અને લાઇવ માઇક હજી જોડાયેલાં નથી.
GitHub પર આ ફોલ્ડરની અંદરની ફાઇલો repositoryમાં ઉમેર્યા પછી Actionsમાંથી debug APK બનાવી શકાશે.
GitHub મોબાઇલ appમાં repository જોઈ શકાય છે; ZIP ફાઇલ સીધી appમાં ખોલવાથી repository બનતી નથી.
બિલ્ડ સફળ થાય છે તે Actions ચલાવીને જ ચકાસી શકાશે.
