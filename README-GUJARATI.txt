Apno Android પ્રોજેક્ટ — UI સુધારો, વર્ઝન 0.2

આ સોર્સ પ્રોજેક્ટ છે; આ ZIP ઇન્સ્ટોલ કરવાની APK નથી.
Game, Discover, Messages અને Profile સ્ક્રીનની સફેદ થીમ અને પાંચ ટૅબ હવે મોકલેલા ઉદાહરણ પ્રમાણે ગોઠવ્યાં છે.
Ludo Dice પર ટચ કરવાથી ડાઇસ રોલ થાય છે. પોસ્ટ, ફોટો, વિડિયો, લોકલ રૂમ અને પ્રોફાઇલની અગાઉની લોકલ સુવિધાઓ છે.
Google/Facebook/Mobile લૉગિન, લોકો વચ્ચે મેસેજિંગ, અન્ય ગેમ અને લાઇવ વૉઇસ હજી કામ કરતા નથી.

GitHub Actions માં આ પ્રોજેક્ટની ફાઇલો push કરો ત્યારે નવી debug APK build થશે.
જૂની Apno-latest-2026-09-26.apk માં આ નવા ફેરફાર નથી. નવી APK મેળવ્યા વગર જૂની ઇન્સ્ટોલ કરવાથી લુક બદલાશે નહીં.
